### R7-F1 (high) - adequacy framed as sufficient when it is only necessary

> The surveyed tier permits measured or validated language once the adequacy note is satisfied, but
> that note defines only an n under 100 restriction. A survey with 100 biased respondents, or fewer
> than 100 valid pairs for a particular feature because of missing responses, can therefore be
> described as validated. `measure-survey-analysis` explicitly says recruitment bias prevents
> generalization and confidence also depends on methodology and signal strength.

**CONFIRMED.** The round-6 fix separated method from adequacy correctly and then defined adequacy as
a single count threshold, which reads as sufficient. Closed by stating that clearing the count is
**necessary and not sufficient**, and that adequacy also turns on valid paired responses per feature,
recruitment quality and representativeness, with a bare instruction not to write "validated" at any
n if the respondents cannot be shown to represent the users the roadmap serves.

### R7-F2 (high) - the terminal-disposition policy was tested on one boundary only

> The terminal-disposition policy applies to any failed minimization, but the recovery re-check
> covers only storage sentinel B. The egress test observes sentinel A only while minimization is
> faulted, so an implementation can enqueue the raw trace, pass because A has not reached the
> collector yet, then replay A after recovery.

**CONFIRMED.** D19's terminal-disposition row was written to cover both boundaries; the matching
test assertion was added to storage and not to egress. Closed by adding the mirrored egress recovery
assertion.

### R7-F3 (high) - a flat self-contradiction

> The storage test first requires sentinel B to be present at the collector, then requires confirming
> B has not appeared anywhere after recovery. Both conditions cannot hold for the same trace.

**CONFIRMED, and it is a plain writing error rather than a design one.** The recovery assertion said
"has still not appeared **anywhere**", and "anywhere" includes the collector, where the same test
block requires B to be. QA following it would have to fail a correct implementation or silently
reinterpret the word. Closed by naming the sinks explicitly and stating that B is expected at the
collector throughout, which is the test's setup rather than a failure.

### R7-F4 (high) - two point estimates and an N do not establish noise

> The sample declares Cohere's 0.83 versus OpenAI's 0.81 recall difference to be within the noise of
> a 200-pair evaluation set. Two point estimates and N do not establish that conclusion. Per-query
> paired outcomes or an uncertainty calculation are required, and the unsupported conclusion helps
> dismiss the nominally best model.

**CONFIRMED, and it is the same class as D15 in release content.** The claim entered at
`922d3303`. Closed by claim-reduction rather than by adding an analysis: the gap is now stated as
**unresolved rather than dismissed**, with the observation that no per-query paired analysis was
run, and the decision explicitly rests on the cost and vendor arguments that do not depend on
resolving it.
